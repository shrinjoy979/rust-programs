# Rust Programs 🦀

A collection of Rust programs and mini-projects created while learning and exploring the Rust programming language.

This repository covers core Rust concepts such as ownership, borrowing, structs, enums, iterators, multithreading, message passing, external packages, and small CLI games.

## 📚 Topics Covered

- Ownership & Borrowing
- Structs & Enums
- Iterators
- Multithreading
- Message Passing & Channels
- External Crates / Packages
- Basic Rust Syntax & Concepts
- Game Development in Rust

## 🎮 Mini Projects

### 🍎 Guess the Fruit
A simple command-line guessing game demonstrating basic Rust logic and user interaction.

### ❌ Tic-Tac-Toe
A command-line Tic-Tac-Toe game implemented in Rust.
